# 시험장 탐지 결과 분류 · v0.2

- **의심 기기**: 전파 광고 이름에 스마트안경·카메라·이어폰·스마트워치를 나타내는 단어가 있을 때 **검토 우선**으로 분류합니다. 부정행위가 확인됐다는 뜻이 아닙니다.
- **스마트폰·핫스팟**: Galaxy S/Z/A, iPhone, Pixel 등 명확한 휴대전화 모델명 또는 일반적인 핫스팟 이름이 포함될 때 추정합니다. Wi-Fi 스캔으로 스마트폰 자체를 찾아내는 것이 아닙니다.
- **일반 가전·설비**: 냉장고·세탁기·공기청정기·에어컨·통신사 공유기 등의 이름이 명확할 때 추정합니다.
- **분류 불명**: 이름 없는 BLE, 숨겨진 SSID, 임의 문자열 등입니다. **안전하거나 정상이라고 간주하지 않습니다.**

## 검사 방식

1. 감독관이 앱을 실행해 검사를 시작합니다. 초반 20초는 기준 신호를 기록하며 신규 여부 구분에 활용합니다.
2. 아래 목록에서 `검토 대기`(미확인 신호) 또는 각 유형을 선택해 항목별로 확인합니다.
3. 신호의 이름/종류/강도/최근 관측 시각을 확인하고 `상세 / 분류 수정`을 엽니다.
4. 실제 시험장 규정에 따라 추가 확인이 필요한 경우 직접 확인한 뒤 체크박스 `확인 완료`를 선택합니다.
5. 분류 근거가 부정확하면 `분류 수정`에서 수동 변경하고, 기록은 CSV에 남깁니다.

## 해석 주의

- 1개 관측 신호가 반드시 1개 물리 기기인 것은 아닙니다. BLE MAC 랜덤화, 공유기 다중 BSSID 등의 영향이 있습니다.
- 주변 교실과 실외의 신호도 잡힐 수 있습니다. RSSI만으로 거리·좌석을 확정할 수 없습니다.
- Wi-Fi 접속점 목록은 모든 스마트폰·카메라·연결 클라이언트의 목록이 아닙니다.
- 이 앱은 활성 무선 **송출 신호** 일부만 관측합니다. 송신하지 않는 카메라나 순수 수신기 탐지 보장은 없습니다.
- 원시 MAC 주소를 CSV에 내보내지 않고, 세션 내 가명 ID를 사용합니다. 새 이름을 발견하면 분류가 갱신될 수 있으며 수동 분류는 유지됩니다.
- 현재 버전에는 RTL-SDR의 RF 수신 기능이 들어 있지 않습니다.
- 자동 분류는 기기 이름을 조작하면 잘못될 수 있고, 미분류가 많이 발생하는 게 정상입니다.
