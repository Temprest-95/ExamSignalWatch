# 공개 전 확인할 사항

- [ ] GitHub Actions 또는 Android Studio에서 실제 APK 컴파일 성공
- [ ] 개발 중 설치 기기에서 앱 정상 실행 확인
- [ ] 근처 기기 / 정확한 위치 권한 허용·거부 각각 시험
- [ ] BLE 실제 광고 신호 수신 확인 (장치 모델과 방출 조건 기록)
- [ ] Wi-Fi AP 신호 수신 확인 및 Android 검색 제한 확인
- [ ] 20초 기준 측정과 신규 신호 표시 구분 확인
- [ ] 앱을 떠날 때 검사 종료 및 데이터 보존 확인
- [ ] CSV 저장·한글 인코딩·삭제 기능 확인
- [ ] 스마트폰별 오탐과 미탐 기록
- [ ] 실제 RF-SDR 수신을 지원한다고 표현하지 않을 것
- [ ] 공개 APK 서명·버전 관리 및 SHA-256 해시 공개
- [ ] 외부 의존 코드 도입 시 LICENSE/NOTICE 최신화
- [ ] 공식 시험장에서 사용할 때 시험 시행기관 승인 확인
- [ ] 실업급여 관련 개인 상황의 행정 판단은 관할기관에 확인

**시험장 부정행위 적발 보장이나 교실 내 기기 전수 탐지 등의 표현을 사용하지 않습니다.**
