# 개발 및 통합 노트

## 기술 설계

- `MainActivity.kt`: 접근 권한, 20초 기준 측정, 관측 목록, CSV 내보내기, 도움말, 전면 표시 유지
- `SignalScanner.kt`: 12초 BLE 스캔 + 8초 휴지 반복, Wi-Fi 45초 간격 Scan API 요청 및 결과 브로드캐스트
- `SignalStore.kt`: 로컬 SQLite 기록, 세션 조회, CSV 내보내기, 데이터 삭제
- `SignalModels.kt`: 관측 결과 데이터 모형
- `UsbSdrStatus.kt`: 기본 VID/PID를 이용한 RTL2832 기반 USB 장치 존재만 점검
- `guide_ko.txt`: 네트워크 없이 읽을 수 있는 전체 사용설명서

## 현재 제품이라고 부를 수 없는 부분

정상적 BLE/Wi-Fi 검색 기능을 작성했다고 해서 Android 8~16에서 호환이 입증된 것은 아닙니다. 현재 코드는 시제품이며 **실기기 검증 전**입니다.

## RTL-SDR 향후 연동

일반 Android SDK는 RTL-SDR의 I/Q 수신 함수를 제공하지 않습니다. 아래 요소를 갖춘 뒤에만 RF 기능을 '지원'으로 표시할 수 있습니다.

1. RTL2832U + R820T2/R860 튜너 제어가 가능한 USB host/드라이버 구현 또는 검증된 외부 라이브러리
2. Android USB 권한 처리 및 열거·장치 선택·전원 오류 처리
3. 튜닝 주파수, 샘플링 속도, 게인 조절
4. 수신된 I/Q 샘플을 처리하는 FFT·잡음 기준·신호 검출
5. 수신 불가 대역·짧은 신호·주파수 순차 탐색의 누락률 표시
6. 실기기 RTL-SDR V4 연결 및 주파수별 검증
7. 사용한 외부 코드의 적법한 라이선스 준수 (GPL 구현 통합 시 GPL 소스 공개 요구 가능)

RTL-SDR V4의 일반 수신 대역은 대략 500 kHz~1.766 GHz이며, 2.4/5 GHz 와이파이 및 2.4 GHz 블루투스를 직접 수신할 수 없습니다.
