## 최소 실험 묶음

1. BLE 광고를 송출하는 검증된 개발 보드 또는 비콘 10회
2. 블루투스 기능을 켠 일반 이어폰과 스마트워치 각각 10회 (광고 여부 별도 기록)
3. 와이파이 접속점 10회; 시스템 스캔 제한 발생 횟수 기록
4. 내부 저장형 카메라 및 수신 전용 장비는 탐지 보장이 없음을 확인
5. 주변 교실·복도 송신기 간섭 측정
6. 기기 화면 꺼짐/전화 수신/앱 전환 이후 실제 감시 상태 확인
7. 무선 신호 관측 수와 실제 장비 수가 달라지는 사례 수집

**시험 결과를 확인하기 전에는 탐지율 수치를 광고 자료에 쓰지 않습니다.**
