시험장 무선 신호 관측기 / Exam Signal Watch
공식 사용설명서 · 시제품 v0.3.0

[앱의 목적]
시험장 감독관이 주변에서 관측되는 블루투스 LE 광고 신호와 와이파이 접속점(AP)의 이름·신호 강도·시간을 확인하고 기록하는 무료 오프라인 앱입니다. 시험 시작 전에 존재한 신호와 시험 시작 후 새로 나타난 신호를 구별하고, 확인이 필요한 항목을 앞에 표시합니다.
본 앱은 전자기기의 정체나 소유자, 위치, 부정행위를 판정하지 않습니다. 학교 밖 접속점도 수신될 수 있습니다. 실제 시험에서의 사용은 시험 시행기관의 승인과 감독 지침을 따라야 합니다.

[1. 사용 전 준비]
① 감독관 스마트폰의 블루투스와 와이파이 기능을 켭니다.
② 필요한 '근처 기기' 및 '정확한 위치' 접근 권한을 허용하고, 와이파이 검색을 위해 시스템 위치 서비스를 켭니다.
③ 시험 중 경고음이 발생하지 않도록 설계되어 있습니다. 화면을 켜 둡니다.
④ RTL-SDR 수신기를 연결해도 v0.3에서는 RF 수신 기능이 작동하지 않습니다. USB 인식 참고 상태만 표시합니다.

[2. 시험 전 기준 신호 수집]
① 시험 시작 직전에 앱을 켜고 '시험 전 기준 신호 수집'을 누릅니다.
② 주변 BLE 신호와 와이파이 접속점을 기록합니다. 기준 수집은 자동으로 시험 감시 단계로 넘어가지 않습니다.
③ 최소 90초 동안 수집하는 것을 권장합니다. Wi-Fi 검색 결과가 실제 새로 갱신된 횟수를 화면에서 확인하세요.
④ Wi-Fi 접속점을 '기존 AP 자동 제외 후보'로 인정하려면 같은 BSSID가 서로 다른 정상 갱신 결과에서 2회 이상 관측되어야 하며, 기기 이름상 일반 가전·공유기 등으로 추정되어야 합니다.
⑤ 기준 수집이 90초 미만이거나 신선한 와이파이 검색 결과가 2회 미만이면 시험 시작 시 경고가 표시됩니다. 감독관은 추가 수집 또는 즉시 시험 시작을 선택할 수 있습니다.
⑥ 기준 수집 전에 이미 숨겨 놓은 송신 장비도 존재할 수 있으므로, 기존 신호가 모두 안전하다고 판단하지 마세요. 모든 신호는 기록에 남습니다.

[3. 시험 시작]
① 실제 시험이 시작될 때 '시험 시작' 버튼을 직접 누릅니다.
② 기준 수집 중 여러 차례 확인된 기존 공유기 등은 기본 '우선 확인' 목록에서 접어 둡니다. 전파 검색은 중단하지 않습니다.
③ 시험 시작 이후 처음 관측된 식별자는 '[시험 후 신규]'로 표시됩니다.
④ 이미 존재한 신호라도 시험 중 서로 다른 시간 구간에 재관측된 BLE 신호는 '반복 관측' 목록에서 확인할 수 있습니다. 반복 광고는 일반 BLE 기기에도 흔합니다.
⑤ 기존 AP 자동 제외 대상은 '기존 AP 제외' 목록에서 언제든 확인할 수 있습니다. 해당 행의 '관심 신호로 지정'을 누르면 다시 우선 확인 목록에 표시됩니다.
⑥ '검사 종료 및 기록 저장'을 누르면 현재 검사 내용이 기기 내부에 저장됩니다.

[4. 화면에 표시되는 분류]
의심 기기: 신호의 이름에 스마트안경·카메라·이어폰·스마트워치와 연관된 단어가 포함된 경우입니다. 이름 기반 추정이므로 실제 장비 종류는 확인되지 않았습니다.
스마트폰·핫스팟: 이름에 휴대전화 모델명이나 모바일 핫스팟 단서가 포함된 경우입니다.
일반 가전·설비: 공유기, 냉장고, 세탁기, 공기청정기 등으로 보이는 이름입니다.
분류 불명: 이름이 없거나 이름만으로 식별하기 어려운 신호입니다.

[5. 관측 항목 확인 및 수동 분류]
각 항목에는 '확인 완료' 체크박스와 '상세·분류' 버튼이 있습니다.
'확인 완료'는 감독관이 기록을 검토했다는 의미이며, 적법한 장비라는 판정이 아닙니다.
'상세·분류'에서 관측 수치, 추정 근거, 가명 ID를 확인하고 수동 분류를 수정할 수 있습니다.
기존 AP라도 직접 확인이 필요하면 '관심 신호로 지정 / 알림 제외 해제'를 누릅니다. 같은 버튼으로 해제할 수 있습니다.

[6. 근접 신호 검사]
의심스러운 항목에서 '근접 신호 검사 · 변화 보기'를 누르고 스마트폰을 들고 교실 안을 이동합니다.
선택한 신호의 새 관측값이 들어올 때마다 dBm과 변화 추세를 표시합니다. -40dBm은 같은 조건의 -80dBm보다 강한 신호입니다.
BLE는 광고 신호를 송출하는 시점에서만 값이 갱신됩니다. 와이파이 AP 검색은 Android의 검색 빈도 제한 때문에 약 45초 간격보다 빨리 새 결과를 얻지 못할 수 있습니다. 실제 마지막 관측 시각을 꼭 확인하세요.
신호가 강해졌다고 해서 그 방향이나 좌석에서 송신했다는 증거는 아닙니다. 금속 물체·몸·벽·전파 반사·안테나 방향에 따라 값이 달라집니다. 미터 단위의 정확한 거리는 표시하지 않습니다.

[7. 자동 기존 AP 제외의 정확한 의미]
안전 목록 또는 무선 차단 기능이 아닙니다. 시험 전부터 두 차례 이상 갱신된 '일반 가전·설비 추정 와이파이 접속점'을 경고 목록에서 잠시 접어 두는 기능입니다.
숨김 접속점, 스마트폰·핫스팟 추정, 카메라 관련 이름 등은 자동 제외하지 않습니다. 감독관이 수동으로 관심 신호를 지정할 수도 있습니다.
실제 기기는 SSID와 MAC 주소를 바꾸거나 임의로 설정할 수 있습니다. BSSID도 고유성이나 진위를 완전히 보장하지 않습니다.

[8. 무엇을 탐지하지 못하나요?]
- 송신하지 않는 기기, 전원이 꺼진 기기, 녹화 영상을 내부 저장만 하는 카메라
- 일반적인 Bluetooth 탐색 결과로 나타나지 않는 통신
- 와이파이 공유기에 연결된 클라이언트 기기(카메라·스마트폰 등) 자체의 목록 또는 암호화된 영상·음성 내용
- 수동형 자기유도 이어폰 또는 수신 전용 장비
- RTL-SDR에서만 탐지되는 전용 RF 송신 장비(v0.3 실제 수신 기능 미구현)
- 고속으로 주파수를 바꾸거나 매우 짧게만 송출하는 일부 신호
신호 0건은 전자기기가 없음을 뜻하지 않습니다. 감지 신호가 100건이라고 실제 기기 100대라는 뜻도 아닙니다.

[9. 검색 갱신과 반복 관측에 관한 주의]
같은 BLE 광고를 여러 번 받거나 와이파이 접속점을 여러 차례 검색하는 것은 일반적인 현상입니다. 앱은 BLE의 단순 콜백 횟수가 아니라 서로 다른 10초 구간을 기준으로 반복 관측을 표시합니다. 와이파이는 서로 다른 새 검색 결과를 기준으로 셉니다. 반복 관측을 실제 통신 내용이나 촬영 활동으로 해석할 수는 없습니다.
검색 요청이 시스템에서 제한되거나 결과가 갱신되지 않으면 이전 스캔 결과를 새 관측으로 기록하지 않도록 설계했습니다. 휴대전화 모델에 따라 결과 갱신 여부에 차이가 있으므로 현장 검증이 필요합니다.

[10. 개인정보, 저장과 내보내기]
서버·로그인·광고·인터넷 권한이 없습니다. 통신 내용, 촬영 영상, 녹음 내용을 수집하지 않습니다.
관측 기록은 스마트폰 내부의 SQLite 데이터베이스에 저장합니다. CSV 내보내기에는 종류, 이름, 마지막 RSSI, 관측 시각, 수동 분류, 기존 AP 제외 여부, 시험 중 관측 구간 수 등이 포함됩니다.
실제 BLE 주소와 AP BSSID는 원문 대신 검사 세션별로 달라지는 해시 가명 ID로 저장합니다. 이름(SSID)은 기록에 남을 수 있습니다. 다른 검사와 동일한 기기를 자동 연결하는 기능은 없습니다.
앱의 화면을 벗어나면 v0.3의 탐지가 종료됩니다. '기록·내보내기'에서 기록을 CSV 파일로 저장하거나 전체 삭제할 수 있습니다.

[11. 문제 해결]
'권한 없음' → 시스템 설정에서 근처 기기/정확한 위치 허용
'와이파이 검색 제한' → Android 운영체제 제한. 검색 결과가 나올 때까지 확인
'위치 서비스 꺼짐' → 시스템 위치 서비스 켜기
'USB 수신기 인식' → RTL-SDR RF 수신 활성화를 뜻하지 않음
'동일 기기를 찾지 못함' → 무선 신호를 보내지 않거나 장치 이름/식별자가 변경됐을 수 있음
'앱에서 화면 전환' → 검사 세션이 종료될 수 있으므로 CSV로 기록 백업

[12. 개발·검증 상태]
이 앱은 시험장 검사를 돕기 위한 개인 개발 시제품입니다. BLE/Wi-Fi 관측 코드, 수동 검토, 자동 기존 AP 접기, 근접 RSSI 변화 표시 기능이 작성되어 있습니다. 실제 APK 빌드와 여러 안드로이드 기기에서의 v0.3 실측 검증은 별도로 진행해야 합니다.
