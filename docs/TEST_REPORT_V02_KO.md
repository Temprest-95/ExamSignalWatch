# v0.2 로컬 확인 내역

- `DeviceClassifier.kt`와 `SignalModels.kt`를 로컬 Kotlin/JVM 컴파일러로 컴파일했습니다.
- 스마트워치, 스마트안경, 스마트폰, 공유기, 냉장고, 세탁기, 공기청정기, 미분류 이름 등 주요 분류 예시 13건을 확인했습니다.
- 실제로 수집된 2026-11-18 CSV의 133개 관측 항목을 **이름 기반 규칙으로 재분류하는 테스트**를 했습니다.
  - 의심 기기 추정: 1개 관측 항목 (Redmi Watch)
  - 스마트폰 추정: 0개 관측 항목
  - 일반 가전·공유기 추정: 39개 관측 항목
  - 분류 불명: 93개 관측 항목
- 이 값은 **현재 규칙을 과거 CSV에 대입한 결과**이며, v0.2가 스마트폰에서 실행된 탐지 결과가 아닙니다.
- Android 전체 앱 컴파일/설치/실기기 UI 테스트는 이 작업 환경에 Android SDK가 없어 수행하지 못했습니다. GitHub Actions 빌드 및 실제 스마트폰 검증이 필요합니다.
- RTL-SDR 수신 기능은 아직 미구현입니다.

## 배포/설치 주의

CI의 개발용 디버그 APK는 빌드 때마다 서로 다른 디버그 서명키로 서명될 수 있습니다. 이전 빌드 위에 설치하지 못한다면, 기존 검사 기록을 CSV로 내보내고 이전 버전을 제거한 뒤 새 버전을 설치합니다. 정식 배포에는 고정된 서명키를 별도 관리해야 합니다.
